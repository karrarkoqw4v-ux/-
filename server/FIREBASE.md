# ربط السيرفر بفايربيس

## 1. فرق المهم: ملفين مختلفين تماماً

- **`google-services.json`** (اللي عندك): خاص بتطبيق أندرويد (Flutter). يُستخدم لو ربطنا
  التطبيق نفسه بفايربيس مباشرة (مثلاً إشعارات FCM مستقبلاً). **السيرفر ما يحتاجه.**
- **`serviceAccountKey.json`** (المطلوب للسيرفر): مفتاح يعطي صلاحية كاملة للسيرفر
  يقرأ/يكتب بقاعدة البيانات، بغض النظر عن القواعد (`database.rules.json`).

## 2. كيف تجيب مفتاح حساب الخدمة

1. افتح Firebase Console → مشروعك (`ssus-b6995`).
2. ⚙️ (بجنب "Project Overview") → **Project settings**.
3. تبويب **Service accounts**.
4. اضغط **Generate new private key** → يتنزّل ملف JSON.
5. غيّر اسمه إلى `serviceAccountKey.json` وحطه داخل مجلد `server/` بجنب `main.go`.

**لا ترفع هذا الملف لـ GitHub أبداً** — هو مفتاح كامل الصلاحيات لقاعدة بياناتك.
أضفته بـ `.gitignore` مسبقاً حتى ما ينرفع بالغلط.

## 3. تشغيل السيرفر

```bash
cd server
go run .
```

لو الملف موجود وصحيح، يطلع بالسجل:
```
فايربيس: متصل بـ https://ssus-b6995-default-rtdb.firebaseio.com
```

لو مو موجود، يطلع تحذير بس السيرفر يشتغل طبيعي بدون مزامنة فايربيس
(تسجيل الدخول والمحادثات تشتغل محلياً كما كانت).

## 4. تطبيق القواعد (مهم لأي وصول مستقبلي من التطبيق مباشرة لفايربيس)

السيرفر نفسه (بالمفتاح أعلاه) يتجاوز هذي القواعد دايماً — هي للحماية
لو يوم من الأيام التطبيق صار يتصل بفايربيس مباشرة (بعد ما نضيف له
تسجيل دخول فايربيس Firebase Auth، اللي ما سويناه بعد).

انسخ محتوى `database.rules.json` والصقه في:
Firebase Console → Realtime Database → تبويب **Rules** → الصق → **Publish**.

## 5. شو ينكتب بقاعدة البيانات الحين

- `/users/{uid}` — نسخة عامة من كل حساب (الاسم، اليوزر، الصورة) — بدون كلمة السر أبداً.
- `/usernames/{username}` — لمنع تكرار أسماء المستخدمين.
- `/userConversations/{uid}/{convId}` — فهرس محادثات كل مستخدم.
- `/conversations/{convId}/participants` — أطراف المحادثة.
- `/conversations/{convId}/meta` — آخر رسالة ووقتها.
- `/conversations/{convId}/messages/{id}` — كل رسالة.

هذي حالياً **نسخة إضافية (مزامنة)** للعرض فقط بلوحة فايربيس — مصدر الحقيقة
الفعلي لسا الذاكرة المحلية للسيرفر (`data.json`). إذا تبي فايربيس يصير
المصدر الوحيد (عشان يشتغل من أكثر من سيرفر بنفس الوقت مثلاً)، قول لي
نسوي الخطوة الثانية.
